Configurazione Trunk SIP

ℹ️ Cos'è un Trunk SIP?
Un trunk SIP connette il tuo sistema telefonico a un provider VoIP (es. Twilio, Vonage, VoIP.ms). Configura questi parametri per ricevere/effettuare chiamate telefoniche.
Nome identificativo del trunk
Indirizzo del server SIP del provider
Credenziali fornite dal provider
Numeri associati al trunk (separati da virgola)

Documentazione SIP

🚀 Come configurare SIP con LiveKit

  1. Scegli un provider SIP (Twilio, Vonage, VoIP.ms, ecc.)
  2. Registra un numero di telefono con il provider
  3. Ottieni le credenziali SIP (host, username, password)
  4. Configura il trunk qui sopra con le credenziali
  5. Configura il provider per inoltrare le chiamate al tuo server LiveKit
  6. Avvia il servizio SIP di LiveKit: docker-compose up -d livekit-sip
